അഡ്മിൻ പാസ്‌വേഡ് മാറ്റുക (Change Admin Password)

അഡ്മിൻ കൺട്രോൾ പാനലിലേക്ക് സുരക്ഷിതമായി ലോഗിൻ ചെയ്യാൻ പുതിയ പാസ്‌വേഡ് ഇവിടെ മാറ്റാം.

🛡️ സുരക്ഷാ നുറുങ്ങ് (Security Tip):

പുതിയ പാസ്‌വേഡ് വെബ് ബ്രൗസറിൽ സുരക്ഷിതമായി എൻക്രിപ്റ്റ് ചെയ്ത് (Salted SHA-256) സൂക്ഷിക്കുന്നു. പാസ്‌വേഡ് മാറ്റിയാൽ പുതിയ പാസ്‌വേഡ് ഉപയോഗിച്ച് മാത്രമേ അടുത്ത തവണ ലോഗിൻ ചെയ്യാൻ സാധിക്കൂ.

☁️

ഓൺലൈൻ ഡാറ്റാബേസ് & ബാക്കപ്പ് ഹബ് (Online Database Hub)

നിങ്ങളുടെ ഉപകരണത്തിലും ക്ലൗഡിലും ഡാറ്റ സുരക്ഷിതമായി സൂക്ഷിക്കുക.

🌐

ക്ലൗഡ് ഡാറ്റാബേസ് കണക്ഷൻ (Firebase / Supabase Integration)

വെബ്‌സൈറ്റിലെ പ്രാർത്ഥനാ അപേക്ഷകളും ഉപയോക്താക്കളുടെ പാസ്‌വേഡുകളും തത്സമയം ഓൺലൈൻ ക്ലൗഡ് ഡാറ്റാബേസിൽ സൂക്ഷിക്കാൻ സൌജന്യ Firebase Firestore അല്ലെങ്കിൽ Supabase കണക്റ്റ് ചെയ്യാം.

📥 മുഴുവൻ ബാക്കപ്പ് ഡൗൺലോഡ്

എല്ലാ പ്രാർത്ഥനാ അപേക്ഷകളും പങ്കാളികളുടെ ഡാറ്റയും ഉൾക്കൊള്ളുന്ന സുരക്ഷിത JSON ഫയൽ ഡൗൺലോഡ് ചെയ്യുക.

📂 ബാക്കപ്പ് റീസ്റ്റോർ ചെയ്യുക

നേരത്തെ സൂക്ഷിച്ച JSON ബാക്കപ്പ് ഫയൽ അപ്‌ലോഡ് ചെയ്ത് വിവരങ്ങൾ പുനഃസ്ഥാപിക്കുക.
